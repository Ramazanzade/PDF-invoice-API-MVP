# Invoice API

Multi-language PDF Invoice Generator API with RTL support.

Supported languages: **Azerbaijani**, **Turkish**, **Russian**, **English**, **Arabic** (RTL).

## Features

- Generate professional PDF invoices from JSON
- 5 languages + RTL (Arabic)
- Locale-aware date & currency formatting
- Simple API Key authentication
- Clean, modern invoice design
